## 每頁定位

### 首頁 `index.html`

- **title**：`臨終助念念佛 App｜常明燈 Lasting Lamp · 免費無廣告 · 完全離線`
- 品類詞「臨終助念念佛 App」前置：品牌尚無搜尋量，曝光主要來自品類與場景詞；品牌詞緊隨其後累積認知。
- description 以功能清單（逐字亮起、8 小時、防誤觸、法器音）覆蓋長尾，句末以「即將上架 App Store，歡迎先了解功能與隱私承諾」收尾——App 尚未上架，不使用「立即下載」等無法兌現的行動語。
- JSON-LD 為 `MobileApplication`（含 `offers price 0` 與 `isAccessibleForFree`），`url` 暫指網站本身；待 App Store 連結確定後應改指商店頁（見「後續建議」）。

### 支援頁 `support.html`

- **title**：`常明燈使用說明與常見問題｜臨終助念念佛 App 支援`
- 定位導航型搜尋（品牌 + 使用說明 / 常見問題），品類詞置於分隔號後補強語境。
- description 逐項列出頁內實際小節（選擇佛號與《心經》、誦念時間、紀念摯愛、防誤觸鎖定、法器音、費用與離線），以「立即查閱」收尾。
- JSON-LD 為 `FAQPage`，三則問答與頁面可見文字逐字一致，維持此一致性是硬性約定。

### 隱私政策頁 `privacy.html`

- **title**：`常明燈隱私政策 Privacy Policy｜不收集、不上傳任何個人資料`
- 保留英文「Privacy Policy」：此頁同時作為 App Store 送審的隱私政策網址，審核與英文使用者都會直接尋找該字樣。
- 副題直接給出結論「不收集、不上傳任何個人資料」，把最強的信任主張放進搜尋結果頁。

### 404 頁 `404.html`

- 維持 `noindex`，title 保持簡短導航性質；description 僅為分享 / 預覽場景兜底，不參與收錄。

## 取捨理由

- **不堆砌品類同義詞**：「念佛機」「佛經播放器」等詞雖有搜尋量，但與 App 定位（臨終助念）有偏差，且 title 空間有限，僅在此記錄、不寫入頁面。
- **不加 `Organization` 結構化資料**：本專案為個人公益性質，無正式組織名稱可填；虛構組織實體不可取。待有正式主體時再補。
- **不使用下載類 CTA**：App 尚未上架，description 與頁面一律使用「了解 / 查閱」類行動語；首頁上架說明僅承諾「上架後即可免費下載」（免費為既有事實）。
- **description 控制在約 80–110 字**：中文搜尋結果約顯示 75–90 字，超長只會被截斷，寧可完整收在省略號之前。

## 後續建議

1. **App 上架後**：把首頁 `.store-note` 換成 App Store 下載按鈕；`MobileApplication` JSON-LD 的 `url` 改為商店頁連結，並可補 `downloadUrl`。屆時 description 的 CTA 可改為「免費下載」。
2. **og:image 分頁化**：現有 `og-image.png`（1200×630）三頁共用；若要提升分享點擊率，可為支援頁 / 隱私頁各出一張帶頁面主題文字的變體圖。
3. **提交 Search Console**：以 `sitemap.xml` 手動提交（專案子路徑下 `robots.txt` 不會被讀取，收錄靠 canonical + sitemap）。
4. **twitter:title / twitter:description**：目前依規範回退至 og:*，暫無需重複聲明；若日後需要 Twitter 專屬文案再單獨補。
5. **綁定自訂網域時**：整批更新 canonical、og:url、sitemap 與 404 頁的子路徑前綴。
